# workora-pharmacy-sales-analysis-5.# Pharmacy Sales Analysis – Workora Internship Project

## Project Overview
This project analyses pharmacy sales data to evaluate revenue growth, profitability, medicine performance, and inventory management opportunities.

## Objectives
1. Calculate monthly revenue growth by drug classification.
2. Compare profit margins and unit sales between generic and branded medicines.
3. Identify the top five revenue-generating medicines.
4. Develop evidence-based pharmacy inventory recommendations.

## Tools Used
- Microsoft Excel
- Data analysis and financial calculations
- PDF reporting and data visualisation

## Deliverables
- `Pharmacy_Sales_Analysis.xlsx` – Detailed workbook containing calculations, summaries, and supporting analysis.
- `Pharmacy_Sales_Analysis_Report.pdf` – Three-page pharmacy sales analysis report.

## Key Findings
- Total net revenue: INR 2,156,930.
- Total profit: INR 827,117.
- Overall profit margin: 38.3%.
- Total units sold: 45,731.
- Top five medicines contribute approximately 94% of total revenue.

## Conclusion
The analysis provides insights into medicine-level sales performance, formulation profitability, revenue trends, and inventory management priorities.
